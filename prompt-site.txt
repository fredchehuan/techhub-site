Crie um site one page (página única) para uma empresa de tecnologia chamada "TechHub.ia.br". O domínio sugerido é TechHub.ia.br.ia.br (apenas referência).

O posicionamento da empresa é: somos um time de especialistas em Inteligência Artificial, Dados, Analytics, Ciência de Dados e Desenvolvimento de Software. Contamos com engenheiros de software, engenheiros de dados, cientistas de dados e designers experientes. Atendemos duas frentes principais:
1. Desenvolvimento de MVPs (produtos mínimos viáveis) para startups e pequenas empresas.
2. Outsourcing de profissionais de tecnologia (staff augmentation) para projetos de qualquer porte.

Mensagem central: "IA First" – usamos inteligência artificial em todo o fluxo de trabalho para entregar projetos complexos em menos tempo, com custo acessível e foco em resultados reais para o negócio.

Design e identidade visual:
- Cores primárias: preto (#000000 ou #0A0A0A) e verde (#00FF00 ou #00E676) – tom de verde neon/tecnologia.
- Fundo predominante preto, com detalhes e acentos em verde.
- Tipografia moderna, sans-serif (ex: Inter, Poppins, ou Montserrat).
- Elementos com efeito de glow (brilho) verde, bordas finas, ícones minimalistas.
- Estilo "alta tecnologia" e "agilidade": linhas retas, animações sutis de entrada, microinterações, possibilidade de fundo com grid ou ondas abstratas em tom muito escuro.

REQUISITOS OBRIGATÓRIOS DE SEO (otimização para mecanismos de busca):

1. Estrutura HTML semântica: use as tags corretas (header, nav, main, section, article, footer) para que os robôs entendam a hierarquia do conteúdo.

2. Meta tags essenciais no <head>:
   - <title> título único e descritivo (ex: "TechHub.ia.br | IA First - Especialistas em Dados e Software")
   - <meta name="description"> com até 160 caracteres resumindo os serviços (incluir palavras-chave: IA, dados, analytics, MVP, outsourcing)
   - <meta name="keywords"> (opcional, mas pode incluir "engenharia de dados, ciência de dados, desenvolvimento de software, IA First")
   - <meta charset="UTF-8">
   - <meta name="viewport" content="width=device-width, initial-scale=1.0">
   - <meta name="robots" content="index, follow">
   - <meta property="og:title" e "og:description" para compartilhamento em redes sociais.
   - <meta name="author" content="TechHub.ia.br">

3. Dados estruturados (JSON-LD): insira um script com Schema.org do tipo "Organization" ou "LocalBusiness", contendo nome, URL, descrição, logo, contatos (e-mail, WhatsApp, LinkedIn).

4. URLs amigáveis: como é uma one page, o arquivo deve se chamar index.html. Se houver âncoras internas (#secoes), os IDs devem ser descritivos (ex: "#servicos", "#cases").

5. Acessibilidade e imagens: todas as imagens/SVG devem ter atributo alt descritivo. Ícones decorativos podem ter alt vazio (alt="").

6. Conteúdo textual relevante: os textos das seções (especialmente o título principal, subtítulo e cards) devem conter palavras-chave naturalmente, sem excesso (evitar keyword stuffing).

7. Performance e indexação: garantir que o site carregue rápido (otimizar CSS/JS, usar lazy loading em imagens pesadas, se houver). O código deve ser limpo, indentado e comentado em português ou inglês para facilitar manutenção.

8. Links internos e externos: todos os links (WhatsApp, e-mail, LinkedIn) devem usar atributos adequados (ex: target="_blank" rel="noopener noreferrer" para links externos).

O site deve ser entregue como um único arquivo HTML (ou um zip com HTML/CSS/JS) que eu possa hospedar em qualquer servidor. O código deve ser limpo, comentado, focado em ser facilmente indexado por robôs de busca, e fácil de editar.
